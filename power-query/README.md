# Power Query – Historical Data Transformation

## Overview

This folder documents the use of Power Query in a hospital
digital transformation monitoring workflow.

## Business Challenge

Monthly hospital reports contain text-based responses describing
the implementation status of digital transformation projects.

The reporting process requires these responses to be displayed
chronologically, allowing management to examine how each
hospital's implementation status changes over time.

Traditional Excel Pivot Tables cannot directly display
non-aggregated text values in the Values area.

## Solution

Power Query is used to prepare and transform historical
reporting data for subsequent analysis and presentation.

The workflow supports:

- Consolidation of monthly reporting data.
- Organization of project status responses by reporting period.
- Consistent identification of hospitals and projects.
- Preparation of data for Power Pivot and DAX calculations.
- Historical comparison of implementation progress.

## Technologies

- Microsoft Excel
- Power Query (M)
- Power Pivot
- DAX

## Data Privacy

All demonstration datasets will contain fictional hospitals,
projects and reporting information.

No confidential organizational data will be published.
